# 🏫 Comprehensive Ultra-Master Prompt: منظومة مدرسة الدعم التعليمي

أنت مهندس وتطبيقات AI خبير. مكلّف ببناء وتحديث "منظومة مدرسة الدعم التعليمي" - منصة إدارة وتواصل مدرسية رقمية ذكية متكاملة (Web Application + Node.js Express Server + Android APK) بتصميم عصري وأنيق باللغة العربية والإنجليزية، مبنية باستخدام React + Vite + Tailwind CSS + Capacitor.

---

## 🛠️ 1. البنية التحتية والتقنية (Tech Stack & Architecture)
- **Frontend Framework**: React 18 + Vite (إعداد `base: './'` لضمان عمل كافة مسارات الصور والملفات نسبياً).
- **Styling & UI**: Tailwind CSS مع دعم الكامل للوضع الداكن (Dark Mode) وخط `Tajawal` العربي، وتأثيرات زجاجية (Glassmorphism) وكروت ملونة تفاعلية.
- **Backend Server**: خادم Node.js / Express (`server.js`) يقوم بتقديم ملفات الإنتاج المجمعة من `dist/` مع ميزات المزامنة السحابية وقواعد البيانات المحلية.
- **إدارة البيانات والحفظ (Database & Persistence)**:
  - استخدام `dbService.js` مع آلية `dbLoadCollection` و `dbSaveCollection` لمنع مسح أو تصفير أي بيانات من الـ `localStorage` أو السيرفر عند تسجيل الدخول أو التحديث.
  - دعم المزامنة عبر نقاط API الخادم (`/api/db/load` و `/api/db/save`) برمز أمان خاص (`sp-secure-wifi-sync-token-2026`).
- **تطبيق الأندرويد (Android Capacitor 6)**:
  - بناء تطبيق أندرويد APK مدمج ومحدث باستمرار يتاح للتحميل المباشر من الموقع عبر `/school-portal.apk`.
  - إعداد أيقونات الأندرويد التكيفية (Adaptive Icons) في `android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` مع صورة مربعة 1:1 لضمان ظهور الشعار كاملاً دون مربعات زرقاء أو انكماش.

## 🔑 3. نظام الأدوار والصلاحيات (Role-Based Authorization)
1. **المدير العام (`admin`)**: إشراف كامل على الطلاب، الموظفين، المالية، إعدادات المنظومة، الحافلات، والدروس.
2. **المعلم (`teacher`)**: إضافة الدروس والأجندة الخاصة بمادته وصفه وشعبته، رصد درجات المواد والحضور والغياب.
3. **التلميذ (`student`)**: استعراض الدروس والأجندة المخصصة لصفه وشعبته، جدول الحصص، النتائج والشهادات، وحالة الحضور.
4. **ولي الأمر (`parent`)**: متابعة بطاقة العائلة الموحدة، الأقساط، تذكيرات الواتساب، والتحصيل المالي والأنشطة.

## 📋 4. الميزات الـ 16 الشاملة والمفصلة (Detailed Feature Set)

1. **كروت المواد والدروس التفاعلية**:
   - كروت ملونة بالكامل في `SubjectsModule.jsx`.
   - عند الضغط على كرت المادة تفتح نافذة تدرج الدروس المرفوعة لهذه المادة، وتسمح للمعلم والمدير بنشر دروس جديدة وتحديد الصف والشعبة والمادة.

2. **صيغة تذكير الواتساب المالي**:
   - رسالة مطالبة مالية تفتح الواتساب بالنص المعياري:
     > `الى ولي امر التلميذ ( اسم التلميذ ) نود تذكيركم بضرورة تسديد القسط الشهري المستحق يرجى التسديد في اقرب وقت شاكرين تعاونكم الكريم`

3. **إدارة طلاب النقل والحافلات**:
   - قسم الحافلات `BusModule.jsx` يتيح للمدير تعيين وإزالة أي طالب من الحافلة بنقرة واحدة (`✕`).

4. **إلغاء بطاقة الطالب الرقمية**:
   - حذف خيار ورابط "بطاقة الطالب الرقمية" كلياً من جميع القوائم والشريط الجانبي.

5. **تحديث أيقونات المنظومة والتطبيق (APK)**:
   - قص الشعار المرفق وتأطيره وتحديث أيقونة لسان التبويب، الشعار بالصفحة، والتطبيق المدمج APK.

6. **تخصيص عرض الدروس**:
   - فلترة الدروس المرفوعة لتظهر لكل تلميذ بحسب صفه وشعبته ومادته فقط.

7. **اسم التبويب الرسمي**:
   - الاعتماد الدائم لاسم **"مدرسة الدعم التعليمي"** في `index.html` و `manifest.json`.

8. **دقة الشهادات والنجاح والرسوب**:
   - احتساب المعدل التراكمي وتصنيف العلامات الأقل من 40% كـ **"راسب 🔴"**.
   - إظهار النتيجة الإجمالية للطالب في الشهادة **"راسب 🔴 (أقل من 40%)"** في حال وجود أي مادة راسبة أو معدل أقل من 40%، وإلا **"ناجح ومجتاز 🟢"**.

9. **لوحة الشرف العصرية والتكريم المباشر**:
   - لوحة شرف بتصميم عالي الجمالية مقسمة ومجموعة لكل صف وشعبة على حدة في الرئيسية `Dashboard.jsx`.
   - زر **"إرسال تهنئة لحساب التلميذ 💌"** لإرسال إشعار تهنئة فوري لصندوق رسائل الطالب التلميذ.

10. **البحث والتوجيه في التعاميم والرسائل**:
    - شريط بحث وتصفية الفئة المستهدفة في `MessagesModule.jsx` (الجميع، صف وشعبة، أو أشخاص معينين).

11. **معهد التقوية وتخصيص الأقساط**:
    - قسم `TutoringModule.jsx` يتيح تسجيل وإزالة الطلاب وتحديد **قسط مالي مخصص** لكل تلميذ ($ USD).

12. **إزالة اسم أ. مريم صالح كلياً**:
    - استبدال كافة التسميات القديمة بـ "أ. معلم المادة" في كامل الكود والسجلات.

13. **التذكير المالي القابل للتعديل**:
    - تمكين المدير من اختيار وتعديل صيغة التذكير المالي قبل إرساله في صفحة التعاميم.

14. **تحديد الصف والشعبة في الأجندة اليومية**:
    - إلزام تحديد الصف والشعبة والمادة والمعلم المسؤول عند إضافة واجبات أو دروس يومية.

15. **إضافة الدروس من المعلم والمدير**:
    - واجهات مخصصة تتيح لكل معلم رفع دروسه ومادته لصفه وشعبته.

16. **سجل الحضور والغياب التفاعلي والدقيق**:
    - رصد الحضور والغياب في `AttendanceModule.jsx` مع عداد تفاعلي (يبدأ من 0 ويزداد بمقدار +1 يومياً، وعند اختيار "غائب" يزداد عداد الغياب ويكون حضور ذلك اليوم 0).
    - الربط التفاعلي المباشر مع لوحة تحكم الطالب لتعكس الإحصائيات الحقيقية.

1. **ممنوع تصفير البيانات**: عدم حذف أو تصفير أي سجلات مخزنة محلياً عند تسجيل الدخول أو التعديل.
2. **الاعتماد المالي الموحد**: جميع المبالغ بالأقساط تعرض بـ **$ USD**.
3. **تجميع العائلة الموحد**: تجميع الإخوة الذين يحملون نفس رقم هاتف ولي الأمر في كرت مالي عائلي موحد.
4. **تجميع بدون أخطاء**: تشغيل `npm run build` للتأكد دائماً من خلو المشروعات من أية أخطاء تجميع أو تركيب.
